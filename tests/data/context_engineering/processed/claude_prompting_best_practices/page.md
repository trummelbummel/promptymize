## Claude Prompting Notes

### 1. Give a Clear Role

Set the model role explicitly and define the expected output style.

### 2. Ask for Structured Output

Request schema-like output when possible (sections or key-value format) to improve consistency.

### 3. Iterate With Examples

Use one or two examples when zero-shot behavior is inconsistent across runs.
